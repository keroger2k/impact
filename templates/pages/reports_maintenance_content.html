Maintenance Mode Scheduler

Paste one node per line as hostname,start,stop and mute SolarWinds alerts (Orion "AlertSuppression") for each — alerts are suppressed for that node between the two times, then resume automatically. This mutes alerts only; it does not stop polling, and it does not create an entry in SolarWinds' own Manage Maintenance Schedules screen (that requires a web-session API this app doesn't use — see CLAUDE.md for why). Start and stop are read in your browser's local time and converted to UTC before anything is sent. Use ISO-style timestamps with no timezone offset, e.g.: 

R-SITE01-01,2026-08-10T08:00,2026-08-10T12:00
R-SITE02-01,2026-08-10T22:00,2026-08-11T02:00
